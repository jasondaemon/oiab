HTTPS Setup

Runtime certificate configuration
Trusted local HTTPS

OIAB keeps certificate files under the mounted data directory so Docker rebuilds do not erase them. Use DNS-01/Cloudflare issuance outside the container or mount existing certs into the cert directory.

OIAB_HOSTNAME=overland.daemonadventures.net
OIAB_CERT_MODE=existing
/data/oiab/certs

Future work will add a guarded certificate action API here. For now this central settings page keeps the current hostname/cert paths visible without hardcoding secrets into the repo.
