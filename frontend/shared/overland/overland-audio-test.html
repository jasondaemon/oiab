Audio Test

Use these touch-triggered tests on the Dasaita to compare native HTML audio with WebAudio.

HTML Audio

Not run

Plays a generated WAV through an HTMLAudioElement for about 1 second.

WebAudio Beep

Not run

Creates/resumes an AudioContext and plays a 440 Hz oscillator.

Unlock Audio

Not run

Resumes a shared context and plays a silent buffer from a tap gesture.

Shared Context Beep

Not run

Uses the shared unlocked context to play an oscillator.

Delayed Beep

Not run

Unlocks from a tap, then waits 1.5 seconds before playing.

Buffer Audio

Not run

Plays a generated sine-wave AudioBuffer, closer to emulator mixer output.

Strict Gesture WebAudio

Not run

Creates, resumes, and starts WebAudio entirely inside this tap handler.

Sample Rates

Not run

Tests default, 48 kHz, and 44.1 kHz AudioContext output.

HTML Through WebAudio

Not run

Routes the working HTML audio tone through createMediaElementSource().

State Monitor

Not run

Logs AudioContext state changes and visibility/focus lifecycle behavior.

Microphone Analyser

Not run

Requests microphone permission and logs live analyser energy for 5 seconds.
