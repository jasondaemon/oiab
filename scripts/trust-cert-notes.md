# Trust Certificate Notes

Development certificates generated by `scripts/generate-cert.sh` are not publicly trusted. Install/trust `OIAB_DATA_DIR/certs/oiab.crt` on each client if using local-ca/self-signed mode.

For production/offline trips, use a DNS-01 issued certificate for the configured `OIAB_HOSTNAME` so clients trust HTTPS without installing a custom CA.
